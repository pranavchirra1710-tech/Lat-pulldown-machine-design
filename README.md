# Lat Pulldown Machine Design

## Overview

A complete CAD-based design of a Lat Pulldown Machine developed using
SolidWorks, including a 3D assembly, individual components, and
detailed engineering drawings.

## Project Details

- **CAD Software:** SolidWorks
- **Material:** Stainless Steel
- **Assembly Weight:** 283 kg
- **Technical Drawings:** 14 sheets

## Project Contents

### 3D CAD Models

- Complete assembly model
- Individual component models
- Detailed part geometry

### Engineering Drawings

The project includes a 14-sheet technical drawing package containing
component dimensions, tolerances, surface finish requirements,
material specifications, and manufacturing details.
